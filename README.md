# REWORK Code

Нативный редактор C++ для Windows на C++ и Qt 6 Widgets. Ранняя версия проекта REWORK.

## Возможности

- Стартовый экран с недавними проектами и поиском по ним.
- Открытие и создание папок проектов, вкладки, сохранение файлов UTF-8 и защита от незамеченных внешних изменений.
- Подсветка C++, номера строк, автоотступ, парные скобки и кавычки.
- Изменение масштаба текста: Ctrl + колесо мыши.
- Настраиваемые цвета, живое стекло по принципу Rework Music PRO с лёгким размытием и преломлением, отдельный переключатель прозрачности области кода.
- Плавный переход строки при Enter с возможностью отключения.
- Подсказки и счётчик диагностик через внешний clangd после открытия папки проекта.

## Сборка

Нужны Qt 6 с модулем Widgets, CMake, Ninja и совместимый компилятор C++. Для Windows-сборки проверялась Qt 6.12 с MinGW 13.1. Пример с Qt, CMake, Ninja и компилятором, доступными в PATH:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/Qt/6.12.0/mingw_64"
cmake --build build
New-Item -ItemType Directory -Force app | Out-Null
Copy-Item build/ReworkCode.exe app/ReworkCode.exe -Force
windeployqt --release --compiler-runtime app/ReworkCode.exe
```

Запускайте `app/ReworkCode.exe` вместе с развёрнутыми библиотеками Qt. Путь к Qt измените в соответствии со своей установкой. Сам clangd в комплект приложения не входит: необходим доступный в PATH clangd; для точного анализа проекта может понадобиться `compile_commands.json`.

## Текущие ограничения

Это ранний прототип, не полная замена VS Code. Семантическая подсветка переменных, терминал, переход к определениям и полноценная отладка пока не реализованы. Подсказки clangd поддерживают не все варианты ответа. Живое стекло локально обрабатывает изображение под окном и ограничено 25 кадрами в секунду; его поддержка зависит от Windows и типа содержимого за окном. Пока оно активно, окно исключено из снимков и записи экрана. Чтобы сделать снимок или показать код в демонстрации экрана, включите «Вид → Режим скриншота» (фон на паузе); для продолжения живого фона отключите этот пункт. При недоступности захвата используется системное стекло DWM. Анимация перехода строки отключается следующим вводом.

Поддерживаются файлы UTF-8; смешанные окончания строк при сохранении могут приводиться к одному стилю. Перед использованием с важными проектами сохраняйте резервные копии.
